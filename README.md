# Lyric Roll

**DAW のピアノロール画面と TextAlive を融合させた、インタラクティブ・リリックアプリです。**

お気に入りの曲を選ぶと、歌詞が DAW のピアノロールのように一文字ずつの「ノート」となって流れていきます。
さらに、画面をタッチ／なぞるとその瞬間のコードに合った音が鳴り、歌詞を動かしながら伴奏を演奏しているような体験ができます。
「聴く」だけでなく「触って遊べる」ことを目指した、ボーカロイド楽曲のためのリリックアプリです

## コンセプト

音楽制作において欠かせない**DAW のピアノロール**を、そのまま「歌詞を鑑賞・操作する場」としました。

- 歌詞は MIDI ノートのようにブロック化され、拍グリッドに吸着して**音楽的なタイミング**で流れます。
- ピアプロキャラクターのカラーで段（レーン）を色分けし、視覚的に華やかにしました。
- 再生ラインの上では、歌声の音量に反応して**光るボールの大きさが変化**し、さらにポルタメントやしゃくり、ビブラートを伴う擬似ピッチカーブを描きます。
- 画面に触れると、**現在のコード進行に沿ったタップ音**が鳴り、適当に触れても不協和音にならず伴奏のように響きます。

## 主な機能

### ピアノロール型の歌詞表示
TextAlive の解析データから歌詞を一文字単位の「MIDI」に分解し、横 6 本の段に配置して再生ラインへ流します。
MIDIの開始位置は**16分の拍グリッドへ自動で吸着**させ、表示が音楽のリズムからズレないようにしています。

### 6 キャラクターカラーの段（レーン）
上から KAITO / 鏡音レン / 初音ミク / 鏡音リン / 巡音ルカ / MEIKO のキャラカラーで段分け。

### タッチ / AUTO の 2 モード
- **タッチ**: 画面をタップ／なぞると、歌詞ノートが流れる段をワード単位で自分で選べます。
- **AUTO**: 確率テーブルに基づく**ランダムウォーク**で段が自動的に選ばれます。鑑賞に適したモードです。

### コードに追従するタップ音（Web Audio API + Tonal.js）
画面をタップ／なぞると、段ごとに割り当てた音が鳴ります。

- **音楽的に違和感のない設計**: 各段にはその時のコードのルートを起点とした**ペンタトニック**を割り当て、不協和音を避けています。
- **「主音＋ルート」の 2 音**で発音し、低音に常にコードのルートが鳴ることで、上もの＋ベースの伴奏のように聞こえます。
- **小節頭のコードで固定**: 小節中にコードが何度も変わる曲でも、小節頭のコードでその小節中は音を固定し、つなぎのコードに音が振り回されないようにしています。
- ボーカルと帯域がかぶらないようタップ音は**低めの音域**に置きました。`タップ音：ON / OFF` ボタンで切り替えられます。

### 擬似ピッチカーブ & VU メーター
- 再生ライン上で**光るボール**がMIDIの配置に合わせて上下。ポルタメント・しゃくり・ビブラートを合成した独自カーブで、ボカロエディタのような動きを再現します。
- ボールは TextAlive の声量データ（`getVocalAmplitude`）を用いて**半径と発光が変化**します。強い声量ほどボールが大きく、強く輝きます。
- 下部の **VU メーター**も声量データで点灯します。疑似的なので装飾用です。

### 計器表示・各種コントロール
- **BPM / 小節 : 拍 / コード名**をリアルタイム表示します。曲ごとのテンポ変化区間にも対応しています。
- **スクロール速度**を ×0.5〜×2.0 で調整可能。遅くすると歌詞が詰まるため、速度に応じてフォントサイズも自動調整します。
- **音量**調整（PC）。※ iOS は仕様上 Web から音量を変更できないため、iOS では音量コントロールを隠します。

### キーボードショートカット（PCのみ）
DAWならではのショートカットキーを実装しました。
- **スペースキー**: 再生 / 一時停止
- **M キー**: モード（タッチ / AUTO）切替

### レスポンシブ & 堅牢性
- PC・スマートフォン（横向き推奨）に対応。スマホでは再生バー・計器をヘッダーへ移し、画面を固定して誤スクロールを防ぎます。
- 通信状況による読み込み失敗・歌詞欠落に備え、**自動リトライ**と分かりやすいエラー表示を実装しています。

## 動作環境

- **対象ブラウザ**: Google Chrome / Microsoft Edge / Safari（いずれも最新版）
- **OS**: Windows / macOS / iOS / Android
- **ネットワーク接続が必要です**（TextAlive API・楽曲データ・Web フォントの取得のため）
- 音が出る環境（スピーカー / イヤホン）を推奨します。
- スマートフォンでは**横向き**での利用が必須です。

> **本番設置に必要なものは HTTP サーバのみです（Node.js は不要）。**
> このアプリは HTML・CSS・JavaScript・フォントだけで構成されており、静的なアプリです。
> サーバ側でプログラムを動かして動的にレスポンスを返すことはなく、配信されたファイルが
> 利用者のブラウザ内だけで動作します。後述の `dist/` フォルダを HTTP サーバに置くだけで動きます。

## 本番設置の手順

ビルド済みの **`dist/` フォルダの中身を、HTTP サーバの公開フォルダにそのままコピーするだけ**です。
Node.js は 開発時とビルド時のツールを動かすためだけに使っています。
サーバへの Node.js のインストールや、サーバ側での起動作業は一切必要ありません。

リンクはすべて相対パス（`vite.config.js` の `base: './'`）なので、ドメイン直下でも
サブディレクトリ配下でも、置いた場所そのままで動作します。

## 開発・ビルド手順（開発者向け）

> ここで使う [Node.js](https://nodejs.org/)（v18 以上を推奨）は、**開発と `dist/` の生成にのみ
> 必要な道具**です。本番サーバや利用者の環境には Node.js は不要です。

```bash
# 1. 依存パッケージのインストール
npm install

# 2. 開発サーバを起動（http://localhost:5173 が開きます）
npm run dev

# 3. 本番用に静的ビルド（dist/ が生成されます）
npm run build

# 4. ビルド結果をローカルで確認
npm run preview
```

`npm run build` を実行すると、上記「本番設置の手順」で使う `dist/` フォルダが生成されます。

## 使い方

1. スタート画面（プロジェクト選択）から曲を選びます。
2. 画面下のトランスポート（▷ 再生 / ❚❚ 一時停止 / □ 停止）で再生します。
3. 左下の**モード切替**ボタンで「タッチ」「AUTO」を切り替えます。
   - **タッチ**: 画面をタップ／なぞると、歌詞ノートが流れる段を単語ごとに選べます。
   - **AUTO**: 段がランダムに選ばれて流れます（タッチ操作はオフ）。
4. **タップ音：ON / OFF** で、画面に触れたときのコード追従サウンドを切り替えます。
5. 速度メーター・スピーカーのアイコンから、スクロール速度・音量を調整できます。

> 初回起動時には「操作方法」ポップアップが自動で開きます（右上の「操作方法」からいつでも再表示可能）。

## プロジェクト構成

```
src/
├ main.js     アプリ本体：楽曲読み込み・段割り当て・Canvas 描画ループ・各種UI
├ sound.js    タップ音の生成（Web Audio API + Tonal.js）
├ config.js   レイアウト・演出のチューニング定数を集約
├ songs.js    収録楽曲リスト（URL・BPM・テンポ変化など）
├ style.css   全体のスタイル
└ fonts/      7セグメント表示フォント（同梱）
index.html    画面構造（スタート画面・ピアノロール・操作方法ほか）
```

描画はライブラリに頼らず、**HTML5 Canvas へすべて自前で実装**しています（歌詞ノート・拍グリッド・ピッチカーブ・ボール・VU メーター等）。

## 使用技術・クレジット

- [TextAlive App API](https://developer.textalive.jp/) — 歌詞・ビート・コード・声量などの楽曲解析データ
- [Tonal.js](https://github.com/tonaljs/tonal) — コード名の解釈と構成音の取得（タップ音の音選び）
- [Vite](https://vitejs.dev/) — ビルドツール
- [Web Audio API](https://developer.mozilla.org/docs/Web/API/Web_Audio_API) — タップ音の合成
- フォント
  - [M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c) / [Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono)（Google Fonts, SIL OFL）
  - [DSEG](https://github.com/keshikan/DSEG)（7 セグメント表示フォント, SIL OFL, © けしかん）— `src/fonts/` に同梱
- 描画はすべて HTML5 Canvas による自前実装です。
