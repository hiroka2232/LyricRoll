操作方法

Lyric RollはDAW上のピアノロール画面とTextAliveを組み合わせたリリックアプリです。タッチやマウスで操作しながら、音楽と歌詞を視覚的に楽しめます。

① 曲（プロジェクト）を選ぶ

  • プロジェクト一覧から気になる曲を選びましょう。

② 再生する

  • □ 停止 / ▷ 再生 / ❚❚ 一時停止で曲を操作します。

③ 歌詞を動かしてみる

  • 左下のモード切替ボタンを押すと、AUTOとタッチを切り替えられます。
  • モード：タッチのとき、画面をタップ／なぞると、歌詞ノートが流れる段を単語ごとに自分で選べます。
  • モード：AUTOのとき、ランダムに歌詞ノートが流れます。このとき、タッチ操作はオフになります。
  • DAWやボーカロイドエディタのような演出をお楽しみください！

④ その他

  • タップ音：タップ音：ON／OFFボタンで切り替えます。ONのとき、ピアノロールをタップ／なぞると、その時の曲のコードに応じて音が段ごとに鳴ります。
  • スクロール速度：速度メーターアイコンから調整できます。
  • 音量：スピーカーアイコンから調整できます。
    ※IOSのみ仕様上調整できないためアイコンが表示されません。
  • 戻る：上部にあるボタンでここに戻れます。
  • (PCのみ) スペースキーで再生/一時停止、Mキーでモード切替ができます。

このアプリは TextAlive App API を利用しています。
